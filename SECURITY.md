# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.
Use [GitHub Private Vulnerability Reporting](https://github.com/XJJ2829/NimbusOps/security/advisories/new) to submit a report directly to the project maintainers.

When reporting, include enough information to reproduce and assess the issue:

- affected component, version or commit;
- a clear description of the impact;
- reproduction steps or a minimal proof of concept;
- suggested remediation, if available.

## Disclosure Process

The maintainers will review valid reports, coordinate remediation where needed,
and publish a disclosure after a fix or mitigation is available. Please allow a
reasonable remediation period before publicly disclosing the vulnerability.

## Scope

Reports are welcome for the NimbusOps Agent Runtime, WebUI, bundled evaluation
workflows and project-maintained deployment scripts. For vulnerabilities in
third-party dependencies, please also consider reporting upstream to the
corresponding project.
